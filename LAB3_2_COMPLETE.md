## 🔄 Конвейер обработки сигнала

```
┌─────────────┐
│  Raw ADC    │  analogRead(A0) → [0-1023]
└──────┬──────┘
       ↓
┌─────────────┐
│ADC→Voltage  │  (adc/1023) × 5V → [0-5V]
└──────┬──────┘
       ↓
┌─────────────┐
│ Salt&Pepper │  Медиана 5 точек → удаление выбросов
└──────┬──────┘
       ↓
┌─────────────┐
│ Weighted Avg│  Взвешенное усреднение → сглаживание
└──────┬──────┘
       ↓
┌─────────────┐
│Voltage→Phys │  voltage × scale + offset → [Physical]
└──────┬──────┘
       ↓
┌─────────────┐
│ Saturation  │  Clamp(min, max) → безопасный диапазон
└──────┬──────┘
       ↓
   Physical Value (°C, Lux, %RH, etc.)
```

## 📚 Теория

### Salt & Pepper (Median) Filter
- **Тип:** Нелинейный фильтр
- **Принцип:** Медиана из окна образцов
- **Преимущества:**
  - Полностью удаляет выбросы
  - Сохраняет резкие переходы
  - Не размазывает сигнал
- **Недостатки:**
  - Требует сортировки (O(n log n))
  - Задержка = половина окна

### Weighted Average Filter
- **Тип:** Линейный фильтр
- **Принцип:** Взвешенная сумма с линейными весами
- **Преимущества:**
  - Быстрая реакция на изменения
  - Приоритет свежим данным
  - Эффективно O(n)
- **Недостатки:**
  - Не удаляет выбросы полностью
  - Может размазывать резкие переходы

### Порядок фильтров
1. **Сначала Salt & Pepper** - удаляем грубые импульсные шумы
2. **Потом Weighted Average** - сглаживаем оставшийся шум

Обратный порядок неэффективен - weighted average размажет выбросы!
