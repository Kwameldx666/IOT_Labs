## 🔄 Конвейер обработки сигнала

```
┌─────────────┐
│  Raw ADC    │  analogRead(A0) → [0-1023]
└──────┬──────┘
       ↓
┌─────────────┐
│ Salt&Pepper │  Медиана 5 точек → удаление выбросов
└──────┬──────┘
       ↓
┌─────────────┐
│ Weighted Avg│  Взвешенное усреднение → сглаживание
└──────┬──────┘
       ↓
┌─────────────┐
│ADC→Voltage  │  (adc/1023) × 5V → [0-5V]
└──────┬──────┘
       ↓
┌─────────────┐
│Voltage→Phys │  voltage × 100 → [°C]
└──────┬──────┘
       ↓
┌─────────────┐
│ Saturation  │  Clamp(-40, 125) → безопасный диапазон
└──────┬──────┘
       ↓
   Physical Value
```

## 🎯 Ключевые особенности

### 1. Правильный порядок фильтров
```
✅ Salt & Pepper → Weighted Average
   (сначала грубая очистка, потом сглаживание)

❌ Weighted Average → Salt & Pepper
   (неэффективно, шум размазывается)
```

### 2. Защита данных (FreeRTOS)
```cpp
// Task 1 пишет
if (xSemaphoreTake(gDataMutex, portMAX_DELAY) == pdTRUE) {
  gSignal1 = localSignal1;
  xSemaphoreGive(gDataMutex);
}

// Task 2 читает
if (xSemaphoreTake(gDataMutex, portMAX_DELAY) == pdTRUE) {
  localSignal1 = gSignal1;
  xSemaphoreGive(gDataMutex);
}
```

### 3. Точное планирование (FreeRTOS)
```cpp
vTaskDelayUntil(&xLastWakeTime, xPeriod);  // Периодичность
vTaskDelay(pdMS_TO_TICKS(offset));         // Смещение
```

## 📚 Дополнительные материалы

### Теория фильтров
- **Salt & Pepper (Median)**: Нелинейный, устойчив к выбросам
- **Weighted Average**: Линейный, быстрая реакция

### Преобразования
- **ADC→Voltage**: Линейная интерполяция
- **Voltage→Physical**: Зависит от датчика (линейная или нелинейная)
- **Saturation**: Защита от выхода за границы

### FreeRTOS
- **vTaskDelayUntil()**: Абсолютное время (периодичность)
- **vTaskDelay()**: Относительное время (смещения)
- **Mutex**: Защита критических секций
